# Изменения

## 1.1.0 — 2026-10-13

- Старт в центре стола с нулевыми MPos/WPos; первый Home привязывает координаты к концевикам. Hard reset сохраняет физическое положение, сбрасывая счётчики.
- Вкладка «Неровности / Heightmap»: область X/Y/W/H, отклонения ±0–10 мм, сетка 2–21 узел по каждой оси, билинейная интерполяция и редактирование высот.
- Рабочая, машинная и прежняя система координат стола для рельефа; отрицательные X/Y, учёт G92 и G54–G59, сохранение параметров в EEPROM.
- Визуализатор Z, толщина материала, контакт щупа по местной высоте и кнопка «Ноль Z» с G38.2 и последующим G92 Z0.
- Ручные концевики действуют пока удерживается кнопка; автоматические контакты включаются вне габаритов и снимаются после возврата внутрь.
- Полная история траектории без прежнего удаления старых отрезков.
- Обновлены README и изображения интерфейса. 121 тест ядра, проверка транспорта и интерфейса.

## 1.0.0 — 2026-10-12

Первый релиз Virtual CNC для Windows x64.

- Протокол GRBL 1.1f: настройки, G-code, EEPROM, realtime-команды и очереди.
- Виртуальные COM-порты, TCP и stdio; единый EXE со встроенным .NET 10.
- Стол XY с пропорциями GRBL, масштабирование колесом и шпиндель с размером по Z.
- G0 серым с прозрачностью 70%; рабочий ход зелёным.
- Виртуальный homing с концевиками, повторным касанием и отходом.
- Начальный рабочий ноль XY G54 в левом нижнем углу; машинные координаты GRBL сохранены.
- Компактная панель управления, цветные датчики, EEPROM с пояснениями и работа в трее.
- 102 теста ядра и проверка TCP-транспорта.

Известные отличия от аппаратного GRBL описаны в README.
