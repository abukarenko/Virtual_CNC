# История изменений

## 1.0.0 — 2026-10-12

Первый релиз Virtual CNC для Windows x64.

- Протокол GRBL 1.1f: настройки, G-code, EEPROM, realtime-команды и очереди.
- Виртуальные COM-порты, TCP и stdio; единый EXE со встроенным .NET 10.
- Стол XY с пропорциями GRBL, масштабирование колесом и шпиндель с размером по Z.
- G0 серым с прозрачностью 70%; рабочий ход зелёным.
- Виртуальный homing с концевиками, повторным касанием и отходом.
- Начальный рабочий ноль XY G54 в левом нижнем углу; машинные координаты GRBL сохранены.
- Компактная панель управления, цветные датчики, EEPROM с пояснениями и работа в трее.
- 102 теста ядра и проверка TCP-транспорта.

Известные отличия от аппаратного GRBL описаны в README.
